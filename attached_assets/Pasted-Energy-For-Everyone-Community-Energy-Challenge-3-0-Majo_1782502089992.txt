Energy For Everyone — Community Energy Challenge 3.0 (Major UX + Engagement Overhaul)
You are working on an existing production-ready React + Express civic application called Energy For Everyone.

The application already contains a Community Energy Challenge page, but it currently feels like a collection of buttons rather than a real community challenge.

Your task is NOT to create a new page.
Instead, transform the existing Challenge experience into something that feels like a real nationwide community initiative that users would actually return to every day.

Maintain the existing architecture:

React 18

TypeScript

Tailwind

shadcn/ui

Zustand

TanStack Query

Express backend

Existing challenge API

The existing styling, routing, responsiveness, and accessibility standards should remain consistent.

Current Problems
The current challenge has several major UX issues that need to be solved.

1. It doesn't feel like a challenge
Users simply click six pledge cards.

They all award the same number of points.

They can all be completed in under a minute.

There is:

no progression

no difficulty

no commitment

no anticipation

no strategy

The experience feels like checking boxes.

Fix this completely.

Overall Design Goal
The finished Challenge should feel less like a static demo and more like a polished civic engagement platform that schools, neighborhoods, clubs, and community organizations could realistically use over weeks or months. Users should have clear goals, meaningful progression, educational value, and compelling reasons to return regularly.
